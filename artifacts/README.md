# Artifacts

This directory stores outputs generated by pipeline stages, analytical plotting scripts, and exploratory dashboards.

## 📊 Contents

- **`emotion_plots/`**: Output directory for generated analytical charts and visual summaries (distributions, radar plots, temporal trends).
- **[`plot_emotion_summary.py`](file:///artifacts/plot_emotion_summary.py)**: CLI script to generate publication-ready emotion and sentiment distribution plots.
- **[`emotion_dashboard.py`](file:///artifacts/emotion_dashboard.py)**: Interactive Streamlit exploratory dashboard for analyzing Reddit emotions.

## 🛠️ Usage

### Generate Analytical Plots
```bash
python artifacts/plot_emotion_summary.py \
  --input backend/data/stopword_lemmatized_posts_0_labels_w_emot.csv \
  --output-dir artifacts/emotion_plots
```

### Launch Interactive Streamlit Dashboard
```bash
streamlit run artifacts/emotion_dashboard.py
```
